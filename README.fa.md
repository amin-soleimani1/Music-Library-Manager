# معماری پروژه

این پروژه بر اساس الگوی **Model – View – Controller (MVC)** توسعه داده شده است تا مسئولیت بخش‌های مختلف برنامه از یکدیگر جدا شوند.

## Model

لایه‌ی Model مسئول نگهداری داده‌ها و ارتباط با دیتابیس است.

در این پروژه از Model برای مدیریت اطلاعات موسیقی و تعامل با SQLite استفاده شده است.

## View

لایه‌ی View شامل تمام بخش‌های رابط کاربری است که با استفاده از CustomTkinter پیاده‌سازی شده‌اند.

این بخش تنها مسئول نمایش اطلاعات و دریافت تعاملات کاربر است.

## Controller

Controller ارتباط بین رابط کاربری و منطق برنامه را مدیریت می‌کند.

در نسخه‌ی جدید، این بخش نسبت به نسخه‌ی قبلی بازطراحی شده است.

در نسخه‌ی اول بسیاری از عملیات بر اساس Indexهای ارسال‌شده از رابط کاربری انجام می‌شد، اما در این نسخه پس از انتخاب یک موزیک، مسیر فایل آن به عنوان مرجع اصلی ذخیره می‌شود و تمام عملیات بعدی بر اساس همان مسیر انجام می‌شود.

این تغییر باعث کاهش وابستگی بین رابط کاربری و منطق برنامه و افزایش قابلیت نگهداری کد شده است.

## Utils

ماژول‌های کمکی پروژه نیز در یک بخش مستقل قرار گرفته‌اند تا از تکرار کد جلوگیری شده و ساختار پروژه خواناتر باشد.

# اجرای پروژه

ابتدا Repository را Clone کنید:

```bash
git clone <repository-url>
```

یک محیط مجازی ایجاد کنید:

```bash
python -m venv .venv
```

وابستگی‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

سپس برنامه را اجرا کنید:

```bash
python main.py
```
